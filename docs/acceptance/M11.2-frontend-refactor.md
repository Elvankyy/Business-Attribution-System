## 已实现

- 登录页改为左侧品牌区 + 右侧登录表单，去掉技术细节文案。
- 工作台右侧新增“历史任务”下拉，切换任务时加载任务状态、工具日志和结果。
- 刷新或切换会话后，从后端任务列表恢复历史任务，不再只依赖 localStorage 的最后一个 task_id。
- 历史工具时间线从 `GET /api/tasks/{task_id}/logs` 读取。
- 助手结论已由后端落库，`done` 后重拉消息能看到“分析完成”消息。
- WebSocket 重连/解析错误会显示在错误横幅。
- 分析运行中只显示“停止分析”，发送按钮隐藏；`sendMessage` 也加了运行中保护。
- `/admin` 路由会调用 `/api/me` 校验 role，非管理员回工作台。
- 附件/结果下载遇到 401 会清理 token 并跳登录，错误会显示后端 detail。
- 管理端数据源/功能开关已有种子配置，不再默认空。
