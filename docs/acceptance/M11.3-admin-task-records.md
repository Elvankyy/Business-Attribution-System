## 功能

- 管理端新增“任务记录”Tab，跨会话展示：
  - 开始时间、会话标题、用户、任务状态、输入问题、任务 ID。
- 日志 Tab 增加“刷新日志”按钮；任务记录 Tab 增加“刷新任务”按钮，解决页面不自动刷新的问题。
- 任务记录每行增加“查看日志”，点击后展开该任务的工具日志；无日志时显示明确提示。
- 后端接口：`GET /api/admin/tasks?limit=50`，可选 `task_status`、`conversation_id` 过滤。
- 返回字段：`task_id`、`conversation_id`、`conversation_title`、`user_id`、`username`、`display_name`、`task_status`、`current_step`、`input_text`、`started_at`、`finished_at`、`error_message`、`result_id`。
- 仅管理员可访问，普通用户返回 403。

## 为什么之前看不到

- 管理端原本只有配置、日志、数据源、功能开关四个 Tab，没有“会话/任务记录”视图；多轮对话只存在工作台和历史任务下拉里。
- 普通用户访问 `/admin` 会被角色守卫送回工作台；需要点击“管理员登录”。
- 管理端只在进入页面时加载数据；如果页面一直开着，之后产生的任务需要刷新或点“重载配置”才会出现。
