## 归因结论
当前商品目录共 6 个在售商品，覆盖 3 个品类：数码（无线耳机 399 元、智能手表 899 元）、家居（护眼台灯 129 元、收纳盒 59 元）、服饰（运动T恤 99 元、跑鞋 499 元），全部为 active 状态。但商品结构呈现明显的"头部集中 + 长尾空转"：仅 3 个商品有实际流量与转化，累计收入约 120.66 万元，其中无线耳机一款贡献 78.80 万元（约 65%），智能手表 38.84 万元（约 32%），两者合计约 97%；护眼台灯仅 3.02 万元。收纳盒、运动T恤、跑鞋三款商品全周期曝光、点击、订单、收入均为 0，属于"上架但未进入流量池"的沉默商品，占商品数一半。因此商品数量看似完整，实际有效在售商品只有 3 个，品类覆盖（尤其服饰品类）名义存在但实质缺位。
